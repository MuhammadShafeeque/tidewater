## Citing and licence

Please cite the software using the `CITATION.cff` file of the repository. The
releases are archived on Zenodo: the DOI
[10.5281/zenodo.23296214](https://doi.org/10.5281/zenodo.23296214) stands for
all versions and resolves to the latest one, and each release has a DOI of its
own on that page. The licence is BSD-3-Clause.
